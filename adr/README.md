- ADR-002: Cola de lecturas pendientes e idempotencia.
- ADR-003: Recuperación del borrador de lectura.
- ADR-004: Conservación de fotos.
- ADR-005: Validación del formulario.
- ADR-006: Persistencia de sesión.
- ADR-007: Mock local (decisión histórica).
- ADR-008: MockAPI remoto.
- ADR-009: Estado compartido con React Context.
